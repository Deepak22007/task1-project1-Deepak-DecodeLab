​This repository contains the complete codebase for Project 1 of the DecodeLabs Industrial Training Program for the 2026 batch.  
​Project Description
​The core goal of this project is to construct a responsive frontend interface for a simple web application that strictly honors the Mobile-First paradigm. Rather than focusing on fixed layout dimensions, this track is centered around adaptability, clean responsive logic, and universal information access. This milestone serves to establish a baseline of digital craftsmanship, attention to detail, and modern frontend UI/UX standards.  
​Key Requirements & Core Skills
​Objective: Create a highly responsive layout capable of handling different screen sizes while preserving a clean, user-friendly UI.  
​The Mandate: Built entirely from scratch using native web technologies with a strict rule of using no frameworks to ensure complete mastery of foundational elements first.  
​Core Skills Showcased: Fundamental frontend development, mobile-first responsive design, and foundational UI aesthetics.  
​The Toolkit & Code Architecture
​HTML5 (The Infrastructure): Developed using proper structural landmark elements—including <header>, <nav>, <main>, <article>, and <footer>—to provide structural meaning, solid search engine indexing, and clean accessibility for screen readers or AI layout parsers.  
​CSS3 (The Skin): Employs CSS Grid to manage macro layouts (the global 2D structural floor-plan) alongside Flexbox to align linear, micro-components like navigation links, logos, and buttons.  
​JavaScript (The Logic): Integrates pure, native scripts to handle lightweight state management and simple interactive web functionalities.  
​Design & Visual Compliance
​The project layout rejects sterile tech aesthetics in favor of visual warmth and grounding through specific architectural standards:  
​Color Palette: Utilizes Mocha Mousse (#A5856F) for structural stability, Ethereal Blue (#A0D4E0) for layout trust, and Moonlit Grey (#F2F0EA) for background refinement.  
​Typography Details: Constrained to a maximum of 2 font families and 3 total weights. It utilizes geometric fonts (such as Montserrat or Inter) for clear headlines paired with highly readable fonts (such as Roboto or Open Sans) for body content.  
​Structural Priority: Grounded in a low-fidelity wireframing strategy matching the rule that if a user interface flow does not work cleanly in grayscale, color choices will not fix it.
Layout Strategy & Responsive Breakpoints
​Single-Column Base: The stylesheet initializes layout code targeting a single-column setup optimized for basic mobile web viewports.  
​Media Query Expansion: Leverages min-width media queries to expand the single column smoothly into macro layout grids at designated breakpoints—specifically Tablet at 768px and Desktop at 1024px.  
​Fluid Typography: Uses the CSS clamp() function to dynamically scale typographical sizing across shifting viewports without rigid break-points.  
​Structured Execution Roadmap
​The interface was engineered by systematically progressing through a 6-step execution framework:  
​Discovery: Mapping target parameters to understand basic user flow constraints instead of guessing.  
​Wireframe: Finalizing mobile-first grayscale hierarchies.  
​Semantics: Constructing explicit HTML landmark configurations.  
​Style: Applying custom layout rules via CSS Grid, Flexbox, and the specified color tones.  
​Logic: Wiring up simple JavaScript click behaviors and basic component states.  
​Audit: Reviewing the output for page optimization metrics and strict web accessibility compliance.
